Embedded E-Ink Calendar

View Code

Programmed firmware for an ESP32 to drive a 7.3-inch, six-color e-ink screen for my embedded calendar application. Built Wi-Fi setup and device pairing, scheduled content downloads, and a physical button for manual refresh. The device sleeps between refreshes to reduce power consumption. Custom PCB for even lower power consumption in the works.

C++ ESP32 Arduino PlatformIO

E-Ink Display Dashboard

View Code

Built a web dashboard and Firebase backend for managing my embedded ESP32 e-ink calendar. Users can connect calendar feeds (.ics), upload photos, and choose views and display settings. Backend is fully scalable with Firebase and can support "unlimited" devices. Backend renders binary images due to limited processing power of the ESP32.

Smart E-Ink Calendar

View Code

Always on ultra-low-power smart calendar display. Hosts local web interface to manage settings, switch modes, change calendars, and upload images. Supports up to four calendars to be added through iCal feeds. Has four different calendar views (day, week, month, list) and refreshes at a specified frequency. Has a secondary mode to double as a digital art frame.

Camera Control System

Demo Video

As part of Engineers for a Sustainable World amphibious camera trap team, I improved the motion detection system and built a control system. The motion detection system uses a Raspberry Pi with a low-res camera to trigger a high-res DSLR. I built and programmed a system to allow adjustment of the system's settings in the field (Article About Project).
